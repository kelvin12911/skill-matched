# workflow-skills

Four skills for everyday coding, research and study, for Claude Code and Codex.

| Skill | Use it for |
|---|---|
| `ship-check` | Before merging: the project's own lint, type check and tests, a browser smoke test of the changed flow, and a diff review, ending in a pass/fail table with evidence. |
| `source-verified-research` | Research where every claim cites a source that was actually opened: official docs for technical claims, original papers for academic work, with verified citation details. |
| `learn-while-coding` | Learn-first coding: concept first, you try first, hints before fixes, recap quiz. Based on Anthropic's study of AI assistance and skill formation. |
| `bilingual-study-pack` | Exam model answers from your own slides and past papers, plus trap and memory notes in your own language, optionally as a checked printable PDF. |

Each skill triggers on its own when a request fits, or call it by name (e.g. `/workflow-skills:ship-check` in Claude Code).
